# Dasar-Mesin-Mesin-Listrik
Proyek ini membahas topik yang sangat menarik, yaitu "Mesin-Mesin Listrik dalam Otomasi Industri". Bersama-sama, kita akan mempelajari komponen-komponen yang menjadi jantung dan otot dari sebuah sistem otomasi, mulai dari Transformator, Kontaktor, hingga evolusi Motor Listrik.
